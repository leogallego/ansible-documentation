# Ansible Core Porting Guides

This section lists porting guides that can help you in updating playbooks, plugins and other parts of your Ansible infrastructure from one version of `ansible-core` to the next.

Please note that this is not a complete list. If you believe any extra information would be useful in these pages, you can edit by clicking <span class="title-ref">Edit on GitHub</span> on the top right, or raising an issue.
